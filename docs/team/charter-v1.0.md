# 团队章程 v1.0

## 1. 团队价值观
- 遇到问题及时沟通，不憋在心里。
- 互相帮助，不甩锅。

## 2. 沟通约定
- 每日站会时间：每晚 9:00 在微信群同步进度。
- 响应时间：看到群消息尽量在 2 小时内回复。

## 3. 开发规约
- 命名规范：类名用大驼峰（如 `UserService`），方法名用小驼峰（如 `getUserById`）。
- 注释：核心业务逻辑必须写注释。
- 代码提交：所有代码必须通过 PR 合并，禁止直接推送到 `main` 分支。

## 4. DoD（完成的定义）
一个任务（Task）只有满足以下条件才算“完成”：
1. 代码编写完毕并能在本地跑通。
2. 通过了至少 1 名队友的代码审查（Review）。
3. 已成功合并到 `main` 分支，且没有破坏原有功能。
